Home Body Wireframe — Editorial Statement

The four home body sections below the shipped slim header — hero, optional marquee band, featured collection (with its own products beneath), recommended products (config order homeSectionOrder: ["hero", "featuredCollection", "recommendedProducts"]). This is the chosen direction (Variant A — Editorial Statement); the Inverted Drama and Swiss Hairline variants were discarded. Since this mock was approved, the hero gained an optional full-bleed photo backdrop (config content.hero.image → live shop brand.coverImage → none) with a primary-token scrim and white on-primary text, and the CTA was slimmed to a 44px-tall gold block — see the hero rules in pages/home.md. The mock below shows the plain text hero; the photo layer sits behind it when media is present. Rules held from design-system/e-commerce-website/MASTER.md: black/white + a single gold accent, radius 0, 1px line separation, section padding ≥ 96px, one statement per section, 4:5 portrait product crop with pinned meta rows, giant display type (clamp(3rem, 10vw, 12rem), weight 900, −0.05em).

Photography is placeholder tone — real imagery keeps object-fit: cover crops. Motion (subtle scroll reveal only, per MASTER) is not simulated; prefers-reduced-motion renders these static states. Implementation record: app/routes/_index/route.tsx + app/src/shared/styles/app.css; design rules persisted in pages/home.md.
